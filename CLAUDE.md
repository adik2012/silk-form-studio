# ПАСПОРТ ПРОЕКТА: Студия авторской колористики «ШЁЛК & ФОРМА | Анна Соколова»

## 1. Главный источник истины

- Вся структура, финальные продающие тексты, дизайн-система, точные цены, тайминги, матрицы квиза и логика корзины находятся в файле **`structure.md`** в корне проекта.
- Запрещено сокращать тексты из `structure.md`, использовать заглушки («рыбу») или писать цены в формате «от ... ₽».

## 2. Обязательные скиллы (Skills)

Перед написанием любого кода обязательно прочитай и строго соблюдай правила из локальных скиллов:

1. `.github/skills/frontend-design/SKILL.md` (или `.claude/skills/frontend-design/SKILL.md`) — верстка, семантика, мобильная адаптивность (375px, 768px, 1440px), отсутствие горизонтального скролла, доступность.
2. `.github/skills/secure-forms-backend/SKILL.md` (или `.claude/skills/secure-forms-backend/SKILL.md`) — безопасность форм, маска телефона `+7`, скрытое honeypot-поле `website`, серверная валидация и пересчет цен в `send.php`, плюс безопасный демо-режим для GitHub Pages.

## 3. Технический стек

- Чистый семантический **HTML5**, современный **CSS3** (CSS Variables из раздела 2 `structure.md`, Flexbox, CSS Grid, `clamp()`), чистый **Vanilla JavaScript (ES6+)** без тяжелых фреймворков.
- Серверный обработчик: **`send.php`** (PHP 8+, защита от спама и XSS, серверный прайс-лист с проверкой цен по ID, длине/объему, проверка промокода `SILK15` и скидки самовывоза `-10%`, отправка в Telegram Bot API / на Email и сохранение резервной копии в `orders.csv`).
- Полная работоспособность на статическом хостинге **GitHub Pages**: если `fetch('send.php')` возвращает ошибку (404/405/network error на статическом хостинге), фронтенд бесшовно переключается в демонстрационный режим портфолио и показывает модальное окно успешного оформления записи / демо-QR СБП.
