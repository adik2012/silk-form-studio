# ШЁЛК & ФОРМА

Учебный демо-проект лендинга вымышленной студии колористики. Все сведения о студии, услугах, ценах, отзывах и клиентах вымышлены.

## Возможности

- Каталог услуг и боксов, корзина, выбор самовывоза или доставки.
- Расчёт стоимости с промокодом `SILK15` и скидкой самовывоза.
- Формы записи с валидацией, маской телефона, согласием на обработку данных и honeypot-полем.
- Серверная проверка состава заказа и цен в `send.php`, запись в CSV и уведомления.
- Демо-оформление и демонстрационный QR-код СБП на GitHub Pages.

## Стек

Семантический HTML5, CSS3, Vanilla JavaScript и PHP 8+. Зависимостей и сборщика нет.

## Локальный запуск

Из корня проекта запустите PHP встроенный сервер:

```powershell
php -S localhost:8000
```

Откройте `http://localhost:8000`. PHP должен быть доступен в PATH.

## Переменные окружения

- `SILKFORM_TELEGRAM_BOT_TOKEN` и `SILKFORM_TELEGRAM_CHAT_ID` — отправка уведомлений в Telegram.
- `SILKFORM_ORDER_EMAIL` — адрес для email-уведомлений, если Telegram не настроен.
- `SILKFORM_ORDERS_PATH` — путь к CSV-журналу заявок; по умолчанию `data/orders.csv`.

## Размещение

На GitHub Pages сайт работает только в демо-режиме: серверный PHP там не выполняется. Для рабочего сервера используйте PHP 8+ и задайте `SILKFORM_ORDERS_PATH` на каталог вне веб-корня. Правила `.htaccess` защищают файлы только на Apache.

## Ограничения демо

- Расписание условное; фиксация занятости хранится только в браузере.
- Серверной защиты от двойной записи нет.
- Промокод `SILK15` публичный.
- Каталог и отзывы формируются JavaScript-кодом.
- Данные о студии, отзывах, услугах и клиентах вымышлены.
